3. Technical requirements

Built with

  • HTML5 — semantic markup, one file per page
  • CSS3 — a single shared stylesheet at css/style.css, using Flexbox for layout
  • Vanilla JavaScript — js/script.js, no external libraries or frameworks

Folder structure

  • home.html, about.html, products.html, contact.html, enquiry.html, planning.html
  • css/style.css — all styling
  • js/script.js — nav highlighting + form validation
  • images/ — logo, product photos, promotional image, QR code

Browser & device support

  • Latest versions of Chrome, Edge, Firefox, and Safari
  • Responsive down to a 360px-wide mobile screen (images and tables scale with max-width: 100%)

Known limitations

  • The enquiry form currently validates on the client side only — no backend is connected yet, so submissions are not actually emailed or stored. This is listed as an upcoming milestone above.
  • No payment processing is included — orders are handled manually via the enquiry form and Instagram.
