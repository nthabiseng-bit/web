# INEEDYOU Authentic Wear- WEDE5020 Part 2
**Repo: **https://github.com/nthabiseng-bit/website

### What the website is about?

INEEDYOU Authentic Wear is a clothing brand based in Middleburg, Mpumalanga, south Africa.
The website shows products, brand info, and how customers can contact the owner Msiza Arnold Ndumiso.
It has 6 pages: Home, About, Product, Contact, Enquiry, and the Planning.

This is Part 2-CSS and Responsive Design

### What i did 

**1.External Stylesheet**

-All pages are linked to one CSS file: 'css/style.css'

-Link used:' <link rel="stylesheet" href="css/style.css"> '

**2.Base Styles**

-I used a simple reset: '*{margin:0; padding:0; box-sizing:border-box;}'

-Font is simple and readable, background is white, text is black. No bright colours-kept it minimal as per brand style.

**3.Typography**

-Used: 'font-family: Arial, sans-serif'

-Headings and paragraphs have different sizes so it is easy to read.

**4.Layout**

-Header uses 'display: flex' to put logo and navigation in one line.

-Desktop shows multi-column layout, easy to navigate.

**5.Visual Style**

-Used simple black border under the header like in screenshot.

-No heavy colours, just black, white, and grey to keep it authentic

### Responsive Design

**Breakpoints I used:**

-Desktop: 1024px and above

-Tablet: 768px to 1023px - layout adjusts

-Mobile: below 768px

**New for Part 2:**

-Added css/style.css and styled all pages

-Made the website responsive for mobile, tablet, and desktops 

-Added hover effects on buttons

-Made images responsive
